# المهندس يوسف (نسخة ثابتة)

نسخة من غير سيرفر: كل الملفات ثابتة، والمفتاح بتاعك بتكتبه جوه التطبيق (⚙️ فوق) ويتحفظ على الجهاز ده بس.

## النشر على GitHub Pages
1. مستودع جديد (Public أو Private لو حسابك فيه Pages للخاص).
2. ارفع الملفات: `index.html`، `sw.js`، `manifest.webmanifest` (والأيقونات جوه الملفات نفسها، مفيش مجلد icons).
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `/ (root)` ← Save.
4. هتاخد لينك `https://اسمك.github.io/اسم-المستودع/`.
5. افتحه ← ⚙️ ← اختار نوع الـ API وحط العنوان والمفتاح والموديل ← احفظ ← اختبر الاتصال.

## مهم
- **المفتاح مش في الملفات**، بس بيتحفظ في متصفح الجهاز ده. أي حد يقدر يفتح المتصفح ده يشوفه. متستخدمش الجهاز ده بالمفتاح على كمبيوتر مشترك.
- المزوّد لازم يسمح بالاتصال من المتصفح (CORS). OpenRouter وGroq وAnthropic بيسمحوا (Anthropic بالهيدر اللي التطبيق بيبعته). لو اختبار الاتصال فشل بـ"CORS"، جرّب مزوّد تاني.
- حط حد صرف عند مزوّدك.
- الملفات مش بتتزامن بين أجهزتك، والنسخة الاحتياطية بتتعمل من «أهدافي وتقاريري ← تصدير».
